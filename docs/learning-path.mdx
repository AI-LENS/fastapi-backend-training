The full curriculum. Each module is one focused concept with a hands-on exercise.

<Note>
  **Time estimate per module:** 30–60 min for read + walkthrough + exercise. Total ≈ 30 hours.
</Note>

<Tip>
  Modules with a letter suffix (e.g. `10b`, `17b`) are **production-grade additions** — patterns that separate "code that works" from "code you can run for real". They're not optional.
</Tip>
