### JWT in 30 seconds

A JWT is three base64-encoded chunks separated by dots:

```
eyJhbGciOi...    .    eyJzdWIiOiJ1c2Vy...    .    abc123signature
   header                  payload                   signature
```

The server signs the payload with a secret. Anyone can decode the payload (it's not encrypted). Only the server (with the secret) can produce a valid signature. Clients send the JWT on every request; the server verifies the signature and trusts the claims inside.

### Why hash passwords with bcrypt

Three properties:

1. **One-way** — can't reverse a hash to get the password
2. **Salted** — each hash includes a random salt (so identical passwords produce different hashes)
3. **Slow** — deliberately computationally expensive to thwart brute force

`bcrypt` (via `passlib`) handles all three for free.

### Step 5 — Auth service

```python app/services/auth_service.py
from datetime import datetime, timedelta, timezone
from typing import Any
from uuid import UUID

from jose import JWTError, jwt
from passlib.context import CryptContext
from sqlalchemy.ext.asyncio import AsyncSession

from app.config import settings
from app.exceptions import DomainError
from app.models.user import User
from app.repositories import user_repository as user_repo


class InvalidCredentials(DomainError):
    code = "invalid_credentials"
    status_code = 401


_pwd_ctx = CryptContext(schemes=["bcrypt"], deprecated="auto")


def hash_password(plaintext: str) -> str:
    return _pwd_ctx.hash(plaintext)


def verify_password(plaintext: str, hashed: str) -> bool:
    return _pwd_ctx.verify(plaintext, hashed)


def _encode(claims: dict[str, Any]) -> str:
    return jwt.encode(claims, settings.secret_key, algorithm="HS256")


def issue_access_token(user: User) -> str:
    now = datetime.now(timezone.utc)
    return _encode({
        "sub": str(user.id),
        "email": user.email,
        "role": user.role,
        "site_id": user.site_id,
        "type": "access",
        "iat": now,
        "exp": now + timedelta(minutes=settings.access_token_minutes),
    })


def issue_refresh_token(user: User) -> str:
    now = datetime.now(timezone.utc)
    return _encode({
        "sub": str(user.id),
        "type": "refresh",
        "iat": now,
        "exp": now + timedelta(days=settings.refresh_token_days),
    })


def decode_token(token: str) -> dict[str, Any]:
    try:
        return jwt.decode(token, settings.secret_key, algorithms=["HS256"])
    except JWTError as exc:
        raise InvalidCredentials("Invalid or expired token") from exc


async def login(db: AsyncSession, email: str, password: str) -> tuple[str, str]:
    user = await user_repo.get_by_email(db, email)
    if user is None or not user.is_active or not verify_password(password, user.hashed_password):
        raise InvalidCredentials("Invalid email or password")
    return issue_access_token(user), issue_refresh_token(user)
```

### Step 6 — User repository

```python app/repositories/user_repository.py
from uuid import UUID

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.user import User


async def get_by_email(db: AsyncSession, email: str) -> User | None:
    result = await db.execute(select(User).where(User.email == email))
    return result.scalars().first()


async def get_by_id(db: AsyncSession, user_id: UUID) -> User | None:
    return await db.get(User, user_id)


async def create(db: AsyncSession, user: User) -> User:
    db.add(user)
    await db.commit()
    await db.refresh(user)
    return user


async def list_all(db: AsyncSession) -> list[User]:
    result = await db.execute(select(User))
    return list(result.scalars().all())
```

### Step 7 — `get_current_user` dependency

```python app/dependencies.py
from fastapi import Depends, Request
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer
from sqlalchemy.ext.asyncio import AsyncSession

from app.exceptions import DomainError
from app.models.user import User
from app.repositories import user_repository as user_repo
from app.services import auth_service


class Unauthorized(DomainError):
    code = "unauthorized"
    status_code = 401


_bearer = HTTPBearer(auto_error=False)


async def get_current_user(
    creds: HTTPAuthorizationCredentials | None = Depends(_bearer),
    db: AsyncSession = Depends(get_db_session),
) -> User:
    if creds is None:
        raise Unauthorized("Missing bearer token")
    payload = auth_service.decode_token(creds.credentials)
    if payload.get("type") != "access":
        raise Unauthorized("Wrong token type")
    # `payload["sub"]` is a string (JWT claim); coerce to UUID for the repo lookup.
    user = await user_repo.get_by_id(db, UUID(payload["sub"]))
    if user is None or not user.is_active:
        raise Unauthorized("User not found or disabled")
    return user
```

(Add `from uuid import UUID` to the imports at the top of `dependencies.py` if it isn't already there.)

### Step 8 — Auth router

```python app/routers/auth.py
from fastapi import APIRouter, Depends
from sqlalchemy.ext.asyncio import AsyncSession

from app.dependencies import get_current_user, get_db_session
from app.models.user import User
from app.schemas.auth import LoginRequest, TokenPair, UserOut
from app.services import auth_service

router = APIRouter(prefix="/auth", tags=["auth"])


@router.post("/login", response_model=TokenPair)
async def login(payload: LoginRequest, db: AsyncSession = Depends(get_db_session)):
    access, refresh = await auth_service.login(db, payload.email, payload.password)
    return TokenPair(access_token=access, refresh_token=refresh)


@router.get("/me", response_model=UserOut)
async def me(user: User = Depends(get_current_user)):
    return user
```

Mount it in `main.py`: `app.include_router(auth.router, prefix=settings.api_prefix)`.

    ```bash
    echo $TOKEN | cut -d. -f2 | base64 -d 2>/dev/null
    ```

  </Step>

## Quick check

<AccordionGroup>
  <Accordion title="Why HS256 and not RS256?">
    HS256 (symmetric) is simpler — single secret, sign and verify with same key. RS256 (asymmetric) is needed when verifiers shouldn't be able to mint new tokens (e.g., a separate identity service issues; many APIs verify). For single-service apps, HS256 is fine.
  </Accordion>
  <Accordion title="What's in `sub`?">
    Standard JWT claim for "subject" — the user ID. Other standard claims: `iat` (issued at), `exp` (expiration), `iss` (issuer). Custom claims have no constraint — we add `role`, `site_id` for convenience.
  </Accordion>
  <Accordion title="How do I revoke a token?">
    You can't, easily — that's the trade-off of stateless JWTs. Production patterns: short-lived access tokens (5-15 min), longer refresh tokens, plus a server-side blocklist for `jti` (token ID) of revoked tokens.
  </Accordion>
  <Accordion title="What about CSRF?">
    Bearer tokens in the `Authorization` header are not CSRF-vulnerable (the browser doesn't auto-attach them). Cookie-based auth is. We use bearer; no CSRF middleware needed.
  </Accordion>
</AccordionGroup>

## Insight

<Tip>
  **`get_current_user` is the single quality gate for "is this request authenticated?"** Routes don't care how the token was decoded; they declare the dependency, FastAPI runs it, and either the route gets a `User` or returns 401. This is the same pattern you'll see in every well-built FastAPI codebase, including AnnotateHub.
</Tip>
