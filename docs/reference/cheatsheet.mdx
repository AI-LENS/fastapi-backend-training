## uv daily commands

```bash
# Install all deps + dev deps from pyproject.toml
uv sync --group dev

# Add a new runtime dep (also updates pyproject.toml)
uv add fastapi
uv add "sqlalchemy[asyncio]>=2.0"

# Add a dev/test dep
uv add --group dev pytest

# Run any command in the project's venv (no activation needed)
uv run uvicorn app.main:app --reload --port 8000
uv run pytest -v
uv run python -c "import fastapi; print(fastapi.__version__)"

# Re-resolve the lockfile
uv lock

# Update a single dep
uv lock --upgrade-package fastapi
```

## Database commands (Module 07+)

```bash
# Create a new migration after editing models
uv run alembic revision --autogenerate -m "describe change"

# Apply migrations to the database
uv run alembic upgrade head

# Roll back the last migration
uv run alembic downgrade -1

# See current revision
uv run alembic current
```

## curl snippets

```bash
# GET
curl http://localhost:8000/screenings

# POST with JSON body
curl -X POST http://localhost:8000/screenings \
  -H "Content-Type: application/json" \
  -d '{"age": 42, "diagnosis": "Type 2 Diabetes", ...}'

# With JWT auth (Module 16+)
curl http://localhost:8000/screenings \
  -H "Authorization: Bearer <your-jwt-here>"

# Pretty-print JSON output (requires jq)
curl http://localhost:8000/screenings | jq
```

## Python snippets you'll repeat

### A FastAPI app

```python
from fastapi import FastAPI
app = FastAPI()

@app.get("/")
def root():
    return {"ok": True}
```

### A path/query/body handler

```python
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    qty: int = 1

@app.post("/items/{cat}", status_code=201)
def create(cat: str, item: Item, source: str | None = None):
    return {"cat": cat, "item": item, "source": source}
```

### A yield-based dependency (DB session)

```python
# from app.database import async_session  ← see Module 05
async def get_db():
    async with async_session() as session:
        yield session
```

### A dependency-injected route

```python
from fastapi import Depends

@app.get("/screenings")
async def list_screenings(db = Depends(get_db)):
    return await screening_repo.list_all(db)
```

### Custom exception handler

```python
from fastapi import Request
from fastapi.responses import JSONResponse

class ScreeningNotFound(Exception): ...

@app.exception_handler(ScreeningNotFound)
async def handle_not_found(_: Request, exc: ScreeningNotFound):
    return JSONResponse(status_code=404, content={"error": str(exc)})
```

## When something breaks

1. Read the error from top — Python stack traces are bottom-up but FastAPI ones are usually top-down for the relevant frame
2. Hit `/docs` — does the route still exist?
3. `uv run python -c "import fastapi; print(fastapi.__version__)"` — right version?
4. `uv sync` — re-install everything from `pyproject.toml`
5. Restart uvicorn (`Ctrl+C` then re-run) — `--reload` occasionally gets confused
